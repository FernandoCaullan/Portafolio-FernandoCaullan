# Proyecto de Portafolio Autoadministrable CMS

##  Resumen
Esta es una web portafolio que permite ver en un index desplegado un modelo de CV, ademas tiene una secion de administracion la cual permite autoadministrar los datos y elementos de la pag

Como un objetivo de aprovar un ramo
## Funciones
- Puedes Emitir mediante un formulario un mensaje
- Puedes ver link redireccion a git y muestra de proyectos
- Puedes ver una seccion de administracion
- Puedes agregar biografia, herramientas, etc. para cada parte del index.

## Tecnologías utilizadas
-  HTML / CSS /php
- JS 
- MYSQL
